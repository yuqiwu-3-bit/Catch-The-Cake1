# Catch-The-Cake1
Introduction：
Catch the Cake is a fast-paced arcade game where players help a hungry princess collect cakes while avoiding falling ice cream bombs. Built with Microsoft MakeCode Arcade, this game was developed as part of a creative coding assignment to explore core programming concepts like conditionals, sprite collisions, state management, and score systems.

Technologies Used：
Microsoft MakeCode Arcade(Python/Blocks)
Installation and Setup
Open MakeCode Arcade
Click “Import” → “GitHub Repo”
Paste https://github.com/yuqiwu-3-bit/Catch-The-Cake1
Press Run to play!

Gameplay Overview：
Control the princess using the arrow keys
Catch as many cakes as possible to increase your score
Avoid falling ice cream bombs – they subtract points!
Watch the princess’s emotions change based on your performance
Earn bonus points through combo streaks (catching multiple cakes in a row)

Features：
Combo Scoring System: Bonus points awarded for catching consecutive cakes
Narrative Intro: Dialog scene that sets up the game goal using the inIntro flag to pause gameplay
Emotional Feedback: Princess sprite switches between happy/sad states depending on your performance
Bomb Penalty: Catching ice cream bombs reduces your score and breaks the combo
Spawn Timing: Controlled via allowSpawn variable and cooldown timer
